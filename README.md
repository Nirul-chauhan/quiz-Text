# quiz-Text
# Introduction
The Quiz Test Application is a web-based interactive system that allows users to answer multiple-choice questions (MCQs) and receive instant feedback.
# Objective of the Quiz Test
To create an interactive quiz system using core web technologies
To practice DOM manipulation and JavaScript logic
To provide instant result and score calculation
To build a clean and responsive UI
# Key Features
Multiple Choice Questions (MCQs)
Start Quiz Button
Next Question Navigation
Instant Answer Validation
Score Calculation
Final Result Display
Restart Quiz Option
# Technologies Used
🔹 HTML
Used to create the structure of the quiz
Buttons, questions, options, and result sections
Semantic elements for better readability
🔹 CSS
Styling the quiz layout
Button hover effects
Responsive design using Flexbox
Clean and user-friendly interface
🔹 JavaScript
Stores quiz questions in an array
Handles question loading and option selection
Validates correct and wrong answers
Updates score dynamically
